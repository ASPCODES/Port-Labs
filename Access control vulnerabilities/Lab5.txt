// Lab: User ID controlled by request parameter


This lab has a horizontal privilege escalation vulnerability on the user account page.

To solve the lab, obtain the API key for the user carlos and submit it as the solution.

You can log in to your own account using the following credentials: wiener:peter.




Hints:

Horizontal privilege escalation occurs if a user is able to gain access to resources belonging to another user, instead of their own resources of that type. For example, if an employee can access the records of other employees as well as their own, then this is horizontal privilege escalation.

Horizontal privilege escalation attacks may use similar types of exploit methods to vertical privilege escalation. For example, a user might access their own account page using the following URL:

https://insecure-website.com/myaccount?id=123

If an attacker modifies the id parameter value to that of another user, they might gain access to another user's account page, and the associated data and functions.




Solution: 

To solve the lab, follow these steps:


1. Log in to your account using the credentials wiener:peter.


2. After logging in, navigate to the account page. The URL should look something like this:

   https://insecure-website.com/myaccount?id=wiener



3. Change the id parameter value in the URL from wiener to carlos, so it looks like this:

    https://insecure-website.com/myaccount?id=carlos



4. Press Enter to load the modified URL. You should now see the account page for the user carlos, which contains the API key you need to solve the lab.



5. Copy the API key for the user carlos and submit it as the solution to the lab.
